## Decisions made
- **OrbStack over Docker Desktop** — free for personal use, much lighter on RAM/battery, speaks Docker natively so docker-compose works unchanged
- **Worker noop stub** — arq refuses to start with zero functions; placeholder is clearly marked TODO Phase 4/5
- **Docker hostname overrides in compose** — `.env` uses `localhost` URLs (correct for running outside Docker); compose `environment:` block overrides them with internal service names for containers
